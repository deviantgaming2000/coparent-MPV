# FactTrail Roadmap

## Phase 1: Working MVP

Status: Complete

- Onboarding / disclaimer screen
- Home screen
- Incident entry
- Neutral summary placeholder
- Summary review
- Timeline view
- Local incident storage
- Export timeline to PDF

## Phase 2: Guided Documentation

Status: In progress

- Category-specific guided questions
- Mock AI interviewer flow without a real AI API
- Evidence type checklist
- Timeline keyword search and filters
- Pattern tags for recurring themes

## Later Phases

- Edit saved incidents
- Store attachments as separate files instead of JSON data
- Optional local-only passcode or device authentication
- Real AI summarization after privacy and safety review
- Export bundles with incident PDFs and original attachments
- Cloud sync only after account, privacy, and consent design

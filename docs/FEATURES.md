# FactTrail Features

## Documentation Flow

FactTrail helps users document parenting and co-parenting events in a neutral, organized way. It does not provide legal advice.

## Current Features

- First-run disclaimer and preservation reminders
- Home screen with quick access to documentation and timeline
- Incident entry with date, people, location, category, child-involved flag, notes, evidence notes, and attachments
- Mock guided interviewer with category-specific clarifying questions
- Evidence type checklist
- Pattern tags for organizing recurring themes
- Local JSON incident storage
- Timeline with expandable incident details
- Timeline search and filters
- PDF export from review and timeline
